# مكتبة الصور الحرة — يلا سكور

مكتبة منظّمة للصور الحرة المعتمدة، فولدر لكل جهة. **خط أنابيب المقالات
(المقال اليومي + تغطية المباريات) يبحث هنا أولًا** قبل أي بحث جديد في
Wikimedia Commons.

> هذا الفولدر لا يُنشر على الموقع (wrangler ينشر `dist/` فقط) — هو أرشيف
> عمل داخل الريبو.

كل فولدر فيه **`INDEX.md`**: جدول (الملف | الموضوع | سطر النسب الجاهز |
أول مقال استخدمها). سطر النسب يُنسخ **حرفيًا** إلى `image_credit`.

## نوعا الصور في الفهرس

1. **بالإشارة (`media/<file>`)** — صورة مُتحقق منها ومستخدمة فعلًا على
   الموقع. تُعاد بنفس الرابط `https://yallascore.site/media/<file>` ونفس
   سطر النسب. **لا تُنقل ولا يُعاد رفعها أبدًا** (صفحات مقالات حية تشير
   إليها).
2. **ملف داخل فولدر النادي (`media-library/...`)** — صورة جديدة لم
   تُستخدم بعد. عند أول استخدام: `git mv` إلى `media/` باسم فريد (لا
   يوجد مسبقًا)، ثم حدِّث مسار الصف في `INDEX.md`.

## إضافة صورة جديدة (خطوات يدوية — للمستخدم)

1. تأكد أن الرخصة **CC BY / CC BY-SA / CC0 / ملكية عامة** من Wikimedia
   Commons (صفحة الملف → قسم Licensing). ممنوع: صور وكالات/صحف،
   شعارات الأندية الرسمية.
2. الجودة: عرض **≥ 800px**، أفقية (landscape) مفضّلة — الصور الطولية
   تتقصقص في غلاف المقال (1544×400).
3. ارفع الملف داخل فولدر الجهة المناسبة (من GitHub: افتح الفولدر →
   `Add file → Upload files`، أو محليًا ثم commit + push).
4. أضف صفًا في `INDEX.md` لنفس الفولدر:
   `| media-library/<الفولدر>/<الملف> | <مَن/ما في الصورة بدقة> | صورة: <الموضوع> — <المصوِّر>، رخصة <الرخصة> (ويكيميديا كومنز) | — |`
5. **الموضوع لازم يكون مُسمّى**: صورة لاعب تُستخدم فقط مع خبر يذكر هذا
   اللاعب بعينه (احذر الأسماء المتشابهة). مشاهد النادي/الملعب/الجماهير
   تصلح لأخبار النادي عمومًا. ألوان القميص لازم تطابق النادي
   (الأهلي أحمر، الزمالك أبيض).

## كيف يستخدمها الـ AI عند النشر (مرجع سريع)

1. حدِّد جهة الخبر → افتح `media-library/<الفولدر>/INDEX.md`.
2. لو فيه صف موضوعه يطابق الشخص/النادي المذكور في الخبر → استخدمه
   (افتح الصورة وشاهدها للتأكد أنها تناسب هذا الخبر تحديدًا).
3. لو مفيش → ابحث في Wikimedia Commons كالمعتاد، وبعد التحقق من أي
   صورة جديدة **سجِّلها صفًا جديدًا في فهرس فولدرها** (المكتبة تكبر
   تلقائيًا مع كل مقال).
4. البديل الأخير فقط: `ph-pitch.svg` بسطر نسب فارغ.
